# 盒子的矩阵课 · 流程演示

像课件一样一步步走的 3D 教学演示：一个彩色方盒子 + 三支箭头 + 原点，用 8 步课程讲清**矩阵是怎么实现旋转、缩放、斜切、位移**的。

## 怎么用

双击 `index.html` 即可（单文件零依赖），或访问本地服务。底部导航条：**「下一步 ▸ / ◂ 上一步 / ▶ 重播本步」**，也可点击步骤圆点跳转，支持键盘 ←/→ 翻页；画布可拖动旋转视角、滚轮缩放。

## 8 步课程

1. **热身**：盒子的身份证——三支箭头（橙x/绿y/青z）+ 原点（蓝圈）；矩阵是它们的登记表
2. **读法**：竖着读，一列 = 一支箭头的新家（自动依次点亮 4 列与箭头联动）；角的"配方阶梯"
3. **位移**：只有第 4 列变，原点搬家 → 盒子整体平移（滑块：tx/ty/tz）
4. **缩放**：只有对角线变，箭头变长/变短 → 方块变鞋盒（滑块：sx/sy/sz）
5. **旋转**：cos/sin 成对出现，盒子刚体转动；转轴上的箭头不动（滑块：θ）
6. **斜切**：一支箭头歪掉 → 扑克牌被推倒，方块变平行六面体（滑块：k）
7. **组合**：M = T·R·Sh·S 四步连乘，重播看盒子依次经历缩放→斜切→旋转→平移（参数来自前面各步滑块）
8. **总结**：一张表带走 + 自由混搭滑块

每步自动播放"从单位矩阵渐变到目标矩阵"的变形动画；右侧矩阵实时显示数值（旋转步带 cos/sin 符号角标），原始盒子保留虚影对照。
